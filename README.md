# StreamCue website

Marketing, support, and privacy pages for the StreamCue iOS app, served by
GitHub Pages at https://streamcueapp.com (set by `CNAME`). This is the
canonical site.

- `index.html` — marketing page
- `support.html` — App Store support URL
- `privacy.html` — App Store privacy policy URL

crankynerdcustoms.com, streamcue.net, and streamcue.us redirect here from
their own repos. The app's code lives in the private `streamcue` repo.
